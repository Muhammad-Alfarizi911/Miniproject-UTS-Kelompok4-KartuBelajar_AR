PETUNJUK TARGET MINDAR
======================
Letakkan file hasil kompilasi bernama  targets.mind  di folder ini
(assets/targets/targets.mind).

Cara membuat:
1. Buka https://hiukim.github.io/mind-ar-js-doc/tools/compile
2. Unggah 4 gambar dari assets/cards/ DENGAN URUTAN:
   card_0_cpu.png -> card_1_ram.png -> card_2_gpu.png -> card_3_motherboard.png
   (urutan unggah = indeks target 0,1,2,3 di app.js)
3. Klik "Start", tunggu selesai, lalu "Download compiled".
4. Ganti nama file hasil unduhan menjadi targets.mind dan taruh di sini.
